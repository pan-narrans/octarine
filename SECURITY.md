# Security Policy

## Supported Versions

Octarine has no public production release yet. Security fixes for current release cycle target
`release/0.1.0`. After stable publication, latest stable release on `master` receives security fixes;
unsupported versions must update.

## Reporting Vulnerabilities

Use GitHub repository **Security → Report a vulnerability** to create private security advisory:

https://github.com/pan-narrans/octarine/security/advisories/new

Include affected version, operating system, impact, reproduction steps, and minimal proof of concept.
Remove vault contents, filesystem paths, credentials, updater private keys, and other personal data.

If private reporting is unavailable, open issue requesting private contact without vulnerability
details. Do not publish exploit details in issue, discussion, or pull request.

Maintainer acknowledges report within seven days, confirms remediation plan when impact is verified,
and coordinates disclosure after fixed release is available.
