# Changelog

Notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) structure and
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Signed stable/beta self-updates for direct macOS and Linux AppImage distributions.
- Public-release security, license, visual, and smoke-test gates.
- Expanded Markdown editor with formatting commands, document outline, split and rendered previews,
  secure internal-link navigation, and attachment import.
- Obsidian-style Live Preview that renders supported Markdown while preserving editable source.

### Changed

- Compact shared workspace layout with narrower navigation, denser task cards, and more editor space.
- Responsive header and editor actions avoid overlap at narrow widths; nested file actions stay below names.
